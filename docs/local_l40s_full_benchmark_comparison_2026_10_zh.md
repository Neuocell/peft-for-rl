# 原 4 x L40S 本机完整评测结果对照

更新时间：2026-10-08（Asia/Shanghai）

本文只整理原 4 x NVIDIA L40S 主机 `app-ebbc492c8b20ba70` 上完成的正式六任务评测。纳入条件是 AIME24、AIME25、AMC23、HMMT Feb、MATH500、Minerva 六项齐全，合并 records 恰好为 7,248 条；当前共 18 个结果满足条件。迁移前旧机器结果、异地 Phase-1 补充结果、后续 8-GPU Qwen3-4B 结果和只有 probe/capture 的诊断均不进入下表。

统一评测使用 902 道题、temperature 0.6、top-p 0.95、max new tokens 32768、eval seed 42。`Macro Avg@k` 和 `Pass@k` 先在任务内汇总，再对六个任务等权平均；`Parse`、`Hit max` 和 `Mean len` 按全部 7,248 次生成汇总。除 `Mean len` 外均为 0--1 比例。表中只对每个逻辑组内最高的 Macro Avg@k 加粗；Pass、Parse、长度和 hit-max 不应被单独当作能力排名。为保持每条比较链自包含，同一 checkpoint 可能出现在多个逻辑组中，但 18 个结果的计数按唯一 checkpoint 计算。

## 1. 低预算初始化方向：step-50 主对照

这组先问：在约 uniform-r8 的低参数预算下，训练前方向选择是否比普通 LoRA 初始化更有效。Standard LoRA、random-B r8 和 SPAR 使用 dropout 0.05；full-gradient r8 与 windowed consensus 使用 dropout 0，因此后两者与前三者不是严格单变量对照。SPAR 是等参数 `eq-r8`，实际 rank 为 `2 / 13.7398 / 32`，不能误写成每层 r8。

## 3. Rank 与训练步数扩展参照

### 3.1 Random-B：同为 step 50 的 r8 与 near-r32

## 5. Phase-1：相同 rank 下的 signal/random 组成

这是本机最干净的初始化几何对照。四组都在原 L40S 上使用 seed42、uniform-r32、alpha64、dropout0、50 steps 和同一 P2 basis；唯一设计变量是初始 A 的 signal 数量。I0/I8/I16/I32 分别包含 `0/8/16/32` 个 signal atom，其余位置由确定性随机正交补空间填充。
